# STEP Montaj

Tarayıcıda çalışan, sunucusuz STEP/IGES/BREP montaj uygulaması.

## Çalıştırma

```
npm install
npm run dev
```

Tarayıcıda http://localhost:5173 adresini açın.

## Derleme

```
npm run build
```

Çıktı `dist/` klasörüne yazılır. Herhangi bir statik sunucuda barındırılabilir.

## Kısayollar

| Tuş | İşlev |
|---|---|
| W / E | Taşı / Döndür |
| Q | Dünya / Yerel eksen |
| F | Seçiliye odakla |
| G | Zemine oturt |
| H | Gizle / Göster |
| Ctrl+D | Çoğalt |
| Del | Sil |
| Ctrl+Z / Ctrl+Y | Geri al / Yinele |
| Esc | Seçimi kaldır |
